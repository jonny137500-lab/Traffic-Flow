# Traffic Flow — Web Edition

A standalone browser game inspired by traffic-flow puzzle games.

Open `index.html` directly or host the repository with GitHub Pages.

The simulation is intentionally kinematic rather than physics-driven: cars use graph routing, smooth acceleration/braking and front-car spacing so the core traffic loop remains stable at high vehicle counts.

## Play

- Desktop: open the page in a modern browser.
- Mobile/tablet: touch-friendly full-screen canvas.
- Pause/reset controls are available in the top-left.

## Verification

The game has no external runtime dependency. The browser is the runtime.
